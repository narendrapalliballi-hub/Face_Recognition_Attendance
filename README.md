Face Recognition Attendance System

Project Description

A real-time face recognition attendance system developed using Python and OpenCV. The system identifies registered students through a webcam and records attendance in an Excel file.

Features

- Real-time face detection and recognition
- Student dataset creation
- Face recognition model training
- Automatic attendance recording
- Excel attendance report

Technologies Used

- Python
- OpenCV
- NumPy
- Pandas
- OpenPyXL

Project Files

- "dataset.py" — Collects student face images.
- "train_model.py" — Trains the face recognition model.
- "attendance.py" — Recognizes faces and records attendance.
- "students.csv" — Stores student IDs and names.
- "haarcascade_frontalface_default.xml" — Face detection classifier.

How to Run

1. Install the required Python packages.
2. Run "dataset.py" to collect student images.
3. Run "train_model.py" to train the model.
4. Run "attendance.py" to start attendance recording.
